Complete Subnetting Guide

What is Subnetting?

Subnetting is the process of dividing a single network into multiple smaller networks (subnets). This improves network performance, enhances security, and makes IP address management more efficient. By borrowing bits from the host portion of an IP address, you create additional network bits, effectively splitting one large network into several smaller ones.

Subnetting Formula

The fundamental formulas for subnetting are:

  • Number of subnets = 2(borrowed bits)
  • Hosts per subnet = 2(host bits) − 2
  • Block size = 256 − subnet mask octet value (for that octet)
  • Network address = IP Address AND Subnet Mask
  • Broadcast address = Network Address OR Wildcard Mask

Frequently Asked Questions

What is a subnet mask calculator?

A subnet mask calculator is a network tool that automatically computes subnet details from an IP address and subnet mask or CIDR notation. It eliminates manual binary calculations and provides instant results including network address, broadcast address, usable IP range, wildcard mask, and binary representation.

How do I calculate usable hosts in a subnet?

Usable hosts = 2(host bits) − 2. You subtract 2 because the network address (all host bits = 0) and broadcast address (all host bits = 1) cannot be assigned to individual devices. For example, a /24 subnet has 8 host bits, so usable hosts = 28 − 2 = 254.

What is CIDR notation?

CIDR (Classless Inter-Domain Routing) notation represents a subnet mask as a slash followed by the number of network bits. For example, /24 means the first 24 bits are network bits, equivalent to subnet mask 255.255.255.0. CIDR replaced the old classful networking system (A, B, C) and allows for more flexible address allocation.

What is a wildcard mask?

A wildcard mask is the bitwise inverse of a subnet mask. Where a subnet mask has 1s for network bits and 0s for host bits, a wildcard mask has 0s for network bits and 1s for host bits. It is commonly used in Cisco Access Control Lists (ACLs) and routing protocols like OSPF and EIGRP to specify which bits must match.

What is the difference between subnetting and supernetting?

Subnetting borrows bits from the host portion to create more, smaller networks. Supernetting (or route aggregation/CIDR aggregation) does the opposite — it combines multiple smaller networks into one larger network by borrowing bits from the network portion. Our calculator detects which operation you are performing relative to the default class mask.

Why do /31 and /32 subnets have 0 usable hosts?

A /31 subnet has only 2 total addresses with no room for network and broadcast addresses, so per RFC 3021 it is used for point-to-point links with both addresses usable. A /32 is a single host route (loopback or specific host), so there are 0 usable hosts in the traditional sense.
